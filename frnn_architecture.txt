KEY DESIGN DECISIONS
════════════════════════════════════════════════════════════════════

  SoA layout  p[d·N + i]     Coalesced warp access — threads 0..31 read consecutive
                             addresses for the same dimension d.

  AoS fast path (D=3)        Sorted queries → warp's 32 threads touch the same cells
                             in lockstep → single L2 broadcast per candidate point.

  float4 distance            When dim%4==0: one 128-bit LDS.128 fetches 4 coords,
                             halving instruction count vs. scalar loop.

  CAP template               Heap array sized at compile time → unrolled sift-down,
                             no branch on heap size, local array in registers.

  AABB pruning               Skips entire cells when their nearest corner is already
                             farther than the current K-th best — eliminates most
                             distance computations at high N.

  Shared-mem tiling (BF)     blockDim.x threads load blockDim.x reference points
                             once; all threads reuse them → BW reduced by blockDim.x.
